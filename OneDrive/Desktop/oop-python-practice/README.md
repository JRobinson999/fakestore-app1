# Hands-On Object-Oriented Python Practice

This project is for practicing Object-Oriented
Programming in Python.

## What This Project Includes

-A 'Student class
-Student Objects
-Methods for adding grades and calculating averages
-A dictionary to find students by email
-A set for unique grades
-Tuple practice
-List operations using '.pop()'
-Email validation using regular expressions
-A bonus count for grades above 90

## How to Run This Project

1.Open this folder in VS Code.
2.Open the terminal.
3.Run this command:

'''bash
python student_practice.py
'''
